# 📊 Xアカウント 0→1 分析ツール

参考にしたい X（旧Twitter）アカウントの投稿データを時系列で分析し、
**どのように認知・フォロワー・信頼を積み上げ、初収益（0→1）を達成したのか** を
解き明かすローカルWebアプリです。

> ⚠️ 無許可のスクレイピングは行いません。データ取得は **CSVインポート** と
> **X公式API**（任意）の2方式のみに対応しています。

---

## このツールでできること

| 画面 | 内容 |
|---|---|
| 🏠 ホーム | 説明・保存済み分析の管理・CSVテンプレートのダウンロード |
| 📥 データ取り込み | CSVアップロード（日本語列名OK）／ X公式APIでの取得 |
| 📊 概要 | 投稿総数・期間・平均/中央値の反応・初収益候補日など |
| 📈 時系列 | 投稿数/反応/カテゴリーの推移・フェーズ自動区分 |
| 📝 投稿分析 | 全投稿の分類一覧・フィルター・伸びた投稿の抽出・CSV出力 |
| 🎯 0→1分析 | 初収益候補の検出と確定・初収益前30日/7日の行動変化 |
| 🤖 AI分析 | Anthropic / OpenAI による深掘り分析（**任意・なしでも動く**） |
| 📄 レポート | 17セクションの分析レポートをMarkdown/CSVで保存 |

投稿は「共感 / ストーリー / 教育 / ノウハウ / 実績 / 権威付け / 日常 / 意見・主張 /
問題提起 / 交流 / 販売 / 商品告知 / 外部誘導 / フォロー訴求 / その他」に自動分類されます。

---

## 必要なもの

- **Python 3.11 以上**（[python.org](https://www.python.org/downloads/) から無料で入手）
- 分析したいアカウントの投稿データ（CSV）
- （任意）X APIのBearer Token、Anthropic / OpenAI のAPIキー

APIキーが1つもなくても、**ルールベース分析ですべての画面が動きます**。

## インストール方法

### 1. このフォルダを開く

**Mac（ターミナル）**
```bash
cd X-reply-ai/x-account-analyzer
```

**Windows（コマンドプロンプト または PowerShell）**
```bat
cd X-reply-ai\x-account-analyzer
```

### 2. 仮想環境を作る（推奨）

仮想環境は「このアプリ専用のPython環境」です。他のツールと干渉しなくなります。

**Mac**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows**
```bat
python -m venv .venv
.venv\Scripts\activate
```

※ 行の先頭に `(.venv)` と表示されたら成功です。
※ 次回以降も、起動前に `source .venv/bin/activate`（Windowsは `.venv\Scripts\activate`）を実行してください。

### 3. 必要なライブラリをインストール

**Mac / Windows 共通**
```bash
pip install -r requirements.txt
```

## 起動方法

**Mac / Windows 共通**
```bash
streamlit run app.py
```

自動でブラウザが開きます（開かない場合は http://localhost:8501 にアクセス）。
終了するには、ターミナルで `Ctrl + C` を押します。

まずは動作確認として、ホーム画面から **架空のサンプルデータ** をダウンロードし、
「データ取り込み」でアップロードしてみてください。

---

## CSVの作り方

必須の列は3つだけです。

| 列名 | 内容 | 例 |
|---|---|---|
| post_id | 投稿のID（重複しない値） | 1234567890 |
| created_at | 投稿日時 | 2025-01-15 09:00 |
| text | 投稿本文 | 今日の学び… |

任意の列: impressions（表示回数）/ likes / replies / reposts / bookmarks / quotes /
url / media_type / followers_count

- **日本語の列名でもOK**です（「投稿日時」「本文」「いいね数」など）。取り込み時に対応付けできます
- ホーム画面から空のテンプレートCSVをダウンロードできます
- X Pro（旧TweetDeck）やアナリティクスのエクスポート、手作業での転記など、
  **利用規約の範囲内で入手したデータ**を使ってください
- impressions がない場合は、いいね等から作った「推定指標」で分析します（画面に明示されます）

## X APIの設定方法（任意）

1. [X Developer Portal](https://developer.x.com/) でアプリを作成し、**Bearer Token** を取得
2. このフォルダで `.env` ファイルを作成:

   **Mac**
   ```bash
   cp .env.example .env
   ```
   **Windows**
   ```bat
   copy .env.example .env
   ```
3. `.env` をメモ帳などで開き、`X_BEARER_TOKEN=` の後にトークンを貼り付け
4. アプリを再起動 →「データ取り込み」の「X公式API」タブが使えるようになります

> 💡 無料プランでは投稿の取得ができない（403エラーになる）場合があります。
> その場合はCSV方式をご利用ください。
> `.env` は `.gitignore` に登録済みで、Gitには保存されません。

## Anthropic APIの設定方法（任意）

1. [console.anthropic.com](https://console.anthropic.com/) でAPIキーを作成
2. `.env` の `ANTHROPIC_API_KEY=` にキーを貼り付けて、アプリを再起動
3. 「AI分析」ページでプロバイダーに「Anthropic API」を選択

## OpenAI APIの設定方法（任意）

1. [platform.openai.com](https://platform.openai.com/) でAPIキーを作成
2. `.env` の `OPENAI_API_KEY=` にキーを貼り付けて、アプリを再起動
3. 「AI分析」ページでプロバイダーに「OpenAI API」を選択

## APIを使わない方法

何も設定しなくてOKです。すべての分析（分類・初収益検出・フェーズ区分・レポート）が
**ルールベース（キーワード＋統計）** で動きます。
AI分析ページでは「AIを使用しない（ルールベース）」と表示されます。

> 🔒 AIを使わない限り、データが外部に送信されることはありません。
> AI分析を実行するときのみ、投稿テキストが選択したAI事業者に送信されます（画面に明示されます）。

## 分析結果の見方

1. **概要** — まず全体像（投稿数・反応の平均と中央値・初収益候補日）を確認
2. **時系列** — 投稿数や反応が「いつ伸び始めたか」、フェーズ区分で発信の変化を確認
   - 「推定」と付いたフェーズは根拠が弱いため参考程度に
3. **0→1分析** — 初収益候補を確認し、正しければ「初収益日として設定」ボタンで確定
   - 見つからない場合は手動で日付を設定できます
4. **投稿分析** — 「伸びた投稿」タブで、いいね上位だけでなく異常値投稿や安定高反応投稿も確認
5. **レポート** — 17セクションのレポートを生成し、Markdownでダウンロード

> 📌 **平均値と中央値の両方を見る**のがコツです。平均が高くて中央値が低い場合、
> 一部のバズ投稿に引っ張られています。

## よくあるエラー

| 症状 | 対処 |
|---|---|
| `streamlit: command not found` | 仮想環境が有効になっていません。`source .venv/bin/activate`（Windows: `.venv\Scripts\activate`）を実行 |
| `ModuleNotFoundError` | `pip install -r requirements.txt` を再実行 |
| CSVで「必須列が見つかりません」 | 列マッピングで post_id / created_at / text に対応する列を選択 |
| CSVの文字化け | ExcelでCSVを「CSV UTF-8」形式で保存し直す |
| X APIで403エラー | APIプランの権限不足です。CSV方式をご利用ください |
| X APIで429エラー | レート制限です。表示された時間だけ待って再実行（取得済み分は保存されています） |
| AI分析で401エラー | `.env` のAPIキーが間違っています。コピーし直してアプリを再起動 |
| ポートが使用中 | `streamlit run app.py --server.port 8502` で別ポートを指定 |

## データの削除方法

- **1つの分析データを消す**: ホーム画面の「削除」ボタン
- **すべてのデータを消す**: アプリを終了し、`data/analyzer.db` ファイルを削除
- **生成したレポートを消す**: `exports/` フォルダの中のファイルを削除

データはすべてローカル（このフォルダ内）に保存されており、削除すれば完全に消えます。

## 利用上の注意

- 本ツールの分析結果は、投稿テキストと公開指標に基づく**推定**です。正確性は保証されません
- 初収益日は投稿の自己申告に基づく候補であり、実際の収益と異なる場合があります
- 分析対象アカウントのデータは、**Xの利用規約の範囲内で入手したもの**を使用してください
- 分析結果を公開する場合は、対象アカウントのプライバシーと権利に配慮してください
- APIキーは `.env` にのみ保存し、他人と共有しないでください
