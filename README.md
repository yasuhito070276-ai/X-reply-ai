# X AIリプ アシスタント

X（旧Twitter）の交流リプを効率化する Chrome 拡張機能です。

- 各投稿に「AIリプ」ボタンを表示
- 投稿の本文と投稿者名を取得
- AI（OpenAI API）がリプを3案生成（本命・親しみ・知見）
  - 「読者が次に知りたいこと」（具体例・初心者向けの入り口・注意点・
    判断基準・例外ケース）を補足する方針で生成
  - APIキー未設定のときは、ルールベース生成（モック）で代用
- 選んだ文章がその投稿の返信欄に自動入力される（編集可能）
- **送信の自動化はしません。最終送信は必ず人間が行います。**

## 構成

```
X-reply-ai/
├── README.md
├── extension/          … Chrome 拡張機能
│   ├── manifest.json      … 拡張機能の設計図
│   ├── content.js         … ボタン追加・投稿取得・候補パネル表示
│   ├── background.js      … 通信係。バックエンドサーバーに生成を依頼
│   └── content.css        … ボタンとパネルの見た目
└── server/             … バックエンドサーバー
    ├── package.json       … サーバーが使うライブラリの一覧
    ├── server.js          … POST /api/replies で投稿を受け取り3案を返す
    ├── ai-generator.js    … OpenAI API でのリプ生成（通信はここだけ）
    ├── reply-generator.js … ルールベース生成（キー未設定時のモック）
    ├── .env.example       … APIキー設定ファイルの見本
    └── .env               … APIキーの実物（各自で作成。GitHubには上がらない）
```

APIキーは拡張機能内には保存しません。AI（OpenAI API）への通信は
バックエンドサーバー経由で行い、キーはサーバーの環境変数（.env）で管理します。

## OpenAI APIキーの設定

```bash
cd server
cp .env.example .env
```

作成された `.env` をテキストエディタで開き、OpenAI のAPIキーを書き込みます:

```
OPENAI_API_KEY=sk-（取得したキー）
OPENAI_MODEL=gpt-5.5
```

設定後にサーバーを起動すると「生成モード: OpenAI」と表示されます。
キーが未設定の場合は自動的にルールベース生成（モック）で動きます。

**注意: `.env` と APIキーは絶対に GitHub や他人に公開しないでください。**
（.gitignore で除外済みですが、キー自体をチャットやSNSに貼らないように）

## Chrome への読み込み方（開発版）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このプロジェクトの `extension` フォルダを選択する
5. https://x.com を開く（すでに開いていたらページを再読み込みする）

## 動作確認

**先にバックエンドサーバーを起動しておいてください**（下記参照）。
サーバーが止まっているとパネルにエラーメッセージが表示されます。

1. タイムラインの各投稿の下（返信・リポストのボタン列の右）に
   「AIリプ」ボタンが表示される
2. ボタンを押すと「リプを生成中…」と表示され、サーバーから返ってきた
   投稿の視点とリプ3案（本命・親しみ・知見）がパネルに表示される
3. 候補をクリックすると、その投稿の返信画面が開き、選んだ文章が
   返信欄に自動入力される（そのまま自由に編集できます）
4. **送信は手動です。** 内容を確認してから、自分で送信ボタンを押します
   （この拡張機能が送信ボタンを押すことは絶対にありません）
5. 自動入力に失敗した場合は、文章がクリップボードにコピーされるので
   手動で貼り付けてください（オレンジ色の案内が表示されます）

`content.js` を修正したときは、`chrome://extensions` で拡張機能の
「更新」ボタン（🔄）を押してから、X のページを再読み込みしてください。

## バックエンドサーバーの起動方法

事前に [Node.js](https://nodejs.org/ja)（LTS版）のインストールが必要です。

```bash
cd server
npm install   # 初回のみ。ライブラリをダウンロードする
npm start     # サーバー起動。止めるときは Ctrl+C
```

**注意:** `npm install` と `npm start` は必ず `server` フォルダの中で
実行してください（先に `cd server` する）。`npm install` を忘れると
起動時に `Cannot find module 'express'` というエラーが出ます。

起動したら、ブラウザで http://localhost:3000 を開いて
「サーバーは動いています」と表示されれば成功です。

API の動作確認（別のターミナルで実行）:

```bash
curl -X POST http://localhost:3000/api/replies \
  -H "Content-Type: application/json" \
  -d '{"author":"テスト太郎","text":"毎朝のルーティンを変えたら人生が変わった"}'
```
