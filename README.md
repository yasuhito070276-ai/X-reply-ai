# X AIリプ アシスタント

X（旧Twitter）の交流リプを効率化する Chrome 拡張機能です。
ChatGPT（Plus などの Web 版）の**専用チャット1つを使い続ける**構成で、
**API・バックエンドサーバー・APIキーは不要**です。

- 各投稿に「AIリプ」ボタンを表示
- 投稿の本文と投稿者名を取得し、専用のリプ生成プロンプトを自動作成
- プロンプトをクリップボードへコピー
- 「X交流リプ専用チャット」のタブを前面表示（無ければ設定したURLを開く）
- ChatGPT が生成した案をコピーして X に戻ると、対象投稿の返信欄へ自動入力
- **X にも ChatGPT にも自動送信はしません。最終送信は必ず人間が行います。**
- ChatGPT の画面（入力欄・送信ボタン）は一切操作しません

## 構成

```
X-reply-ai/
├── README.md
├── extension/          … Chrome 拡張機能（これだけで動く）
│   ├── manifest.json   … 拡張機能の設計図（権限: tabs / storage / clipboardWrite）
│   ├── settings.js     … 設定の既定値と読み込み・プロンプト組み立ての共通処理
│   ├── options.html    … 設定画面（専用チャットURL・プロンプト・案内文）
│   ├── options.js      … 設定画面の保存・読み込み処理
│   ├── content.js      … ボタン追加・投稿取得・コピー・返信欄への入力
│   ├── background.js   … ChatGPTタブを探して前面表示／専用チャットを開く係
│   └── content.css     … ボタンなどの見た目
└── server/             … 【休止中】OpenAI API 版のバックエンド
```

### 使用する権限（必要最小限）

| 権限 | 用途 |
|---|---|
| `tabs` | 開いているタブから ChatGPT のタブを探し、前面に切り替える |
| `storage` | 設定（専用チャットURL・プロンプト・案内文）を保存する |
| `clipboardWrite` | プロンプトをクリップボードへコピーする |

## Chrome への読み込み方（開発版）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このプロジェクトの `extension` フォルダを選択する
5. https://x.com を開く（すでに開いていたらページを再読み込みする）

ファイルを修正したときは、`chrome://extensions` で拡張機能の
「更新」ボタン（🔄）を押してから、X のページを再読み込みしてください。

## 初期設定（専用チャットの登録）

1. ChatGPT で新しいチャットを1つ作り、「X交流リプ専用」などと分かる
   最初のメッセージを送っておく（例:「このチャットではXのリプ案を作ります」）
2. そのチャットの URL（例: https://chatgpt.com/c/xxxxxxxx）をコピー
3. `chrome://extensions` → 「X AIリプ アシスタント」の「詳細」→「拡張機能のオプション」
   （またはツールバーの拡張機能アイコンを右クリック →「オプション」）
4. 設定画面で以下を保存:
   - **X交流リプ専用チャットのURL** … 手順2のURL
   - **リプ生成プロンプト** … 初期値のままでOK（好みに応じて編集可能）
   - **案内文** … 初期値のままでOK

## 使い方

1. タイムラインの投稿の「AIリプ」ボタンを押す
2. プロンプトがコピーされ、案内文が表示された後、専用チャットのタブに切り替わる
   （タブが無ければ設定したURLが新しいタブで開く。毎回新規チャットは作らない）
3. ChatGPT の入力欄に **貼り付け（⌘V）→ 送信**（あなたの操作）
4. 生成された3案（本命・親しみ・知見）から気に入ったものをコピー
5. X のタブに戻り、画面右下の **「📋 コピーした文章を返信欄へ入力」** を押す
   - 対象の投稿（AIリプボタンを押した投稿）の返信欄が開き、自動入力される
   - 初回は Chrome が「クリップボードの読み取りを許可しますか」と
     聞いてくるので「許可」を選ぶ
6. 内容を確認・編集して、**送信は自分で押す**

うまく自動入力できない場合も、文章はコピーされたままなので
返信欄に手動で貼り付ければ OK です。

## 【休止中】OpenAI API 版について

API 版のコード一式はブランチ **`backup/openai-api-version`** に保存してあります。
現在のブランチにも `server/` フォルダを残しています
（起動: `cd server && npm install && npm start`、APIキーは `server/.env` に設定）。
API 版に戻す場合は、バックアップブランチの拡張機能コードを復元してください。
