# X AIリプ アシスタント

X（旧Twitter）の交流リプを効率化する Chrome 拡張機能です。
ChatGPT（Plus などの Web 版）と連携して動き、**API・サーバーは不要**です。

- 各投稿に「AIリプ」ボタンを表示
- 投稿の本文と投稿者名を取得し、専用のリプ生成プロンプトを自動作成
- ChatGPT を新しいタブで開き、プロンプトを入力済みの状態で渡す
- ChatGPT が生成した3案（本命・親しみ・知見）から気に入ったものをコピー
- X に戻って「返信欄へ入力」ボタンを押すと、対象投稿の返信欄に自動入力
- **送信の自動化はしません。最終送信は必ず人間が行います。**

## 構成

```
X-reply-ai/
├── README.md
├── extension/          … Chrome 拡張機能（これだけで動く）
│   ├── manifest.json       … 拡張機能の設計図
│   ├── prompt-template.js  … あなた専用プロンプトの文面（調整はここ）
│   ├── content.js          … ボタン追加・投稿取得・パネル・返信欄への入力
│   ├── background.js       … ChatGPT のタブを開く係
│   └── content.css         … ボタンとパネルの見た目
└── server/             … 【休止中】OpenAI API 版のバックエンド
                           （API版を再開する場合のために残してある）
```

## Chrome への読み込み方（開発版）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このプロジェクトの `extension` フォルダを選択する
5. https://x.com を開く（すでに開いていたらページを再読み込みする）

ファイルを修正したときは、`chrome://extensions` で拡張機能の
「更新」ボタン（🔄）を押してから、X のページを再読み込みしてください。

## 使い方

1. タイムラインの投稿の「AIリプ」ボタンを押す
2. 作成されたプロンプトがパネルに表示される
   - **🚀 ChatGPTで開く（プロンプト入り）** … ChatGPT が新しいタブで開き、
     プロンプトが入力済みになっている（ChatGPT にログインしている必要あり）
   - **📋 コピーしてChatGPTを開く（予備）** … プロンプト入りで開く仕組みが
     使えなくなった場合はこちら。貼り付けるだけの状態でコピーされる
3. ChatGPT がリプ3案（本命・親しみ・知見）を生成する
4. 気に入った案を ChatGPT の画面でコピーする
5. X のタブに戻り、画面右下の **「📋 コピーした文章を返信欄へ入力」** を押す
   - 対象の投稿（AIリプボタンを押した投稿）の返信欄が開き、自動入力される
   - 初回は Chrome が「クリップボードの読み取りを許可しますか」と
     聞いてくるので「許可」を選ぶ
6. 内容を確認・編集して、**送信は自分で押す**
   （この拡張機能が送信ボタンを押すことは絶対にありません）

うまく自動入力できない場合も、文章はコピーされたままなので
返信欄に手動で貼り付ければ OK です。

## プロンプトの調整

リプの方針（禁止ワード・視点の優先順位・3案のスタイル）は
`extension/prompt-template.js` に書いてあります。
このファイルを編集 → 拡張機能を更新、で自分好みに調整できます。

## 【休止中】OpenAI API 版バックエンドについて

現在の拡張機能はサーバーを使いませんが、API 版を再開する場合のために
`server/` フォルダを残してあります（起動: `cd server && npm install && npm start`、
APIキーは `server/.env` に設定。詳細は `server/.env.example` を参照）。
API 版に戻すには拡張機能側の接続コードの復元も必要です。
